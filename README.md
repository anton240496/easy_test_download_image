# Замер скорости загрузки

Консольный скрипт отправляет 10 последовательных GET-запросов к указанному HTTP(S)-адресу. Перед следующим запросом он полностью читает тело предыдущего ответа, подсчитывая полученные байты.

Требуется Node.js 18 или новее (используется встроенный `fetch`).

## Запуск

```text
node download-benchmark.js https://example.com/image.jpg
```

Скрипт выводит время каждого запроса, среднее время, общий объём данных и среднюю скорость загрузки за всё время выполнения десяти запросов.

## Единицы измерения

Объём указывается в **MiB** (1 MiB = 1 048 576 байт), время — в миллисекундах или секундах. Скорость указывается в **MiB/s**: общий фактически полученный объём в MiB делится на общее время десяти запросов в секундах.
